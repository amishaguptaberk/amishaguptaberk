# Amisha Gupta

I build AI products and the systems behind them. My work spans voice AI, tools for evaluating agents, and applications with payments and real-time workflows.

Currently building AI infrastructure at an early-stage startup. I work across the frontend and backend, from the interface to the APIs and integrations.

## Selected work

- **Sonar:** Multi-tenant voice AI platform with telephony, payments, and POS integrations. Built with React, TypeScript, Supabase, Twilio, ElevenLabs, Stripe, and Clover.
- **Surface Hub:** B2B growth platform with LinkedIn analytics and background AI workflows. Next.js, PostgreSQL, Claude API, and async workers.
- **Dynamic Prompt Optimizer:** Evaluation framework for AI voice agents, with a FastAPI backend, React interface, and Claude-as-judge scoring.
- **[Valey](https://github.com/amishaguptaberk/backend_api_rideshare_app):** Rideshare backend and rider/driver apps covering ride requests, live tracking, payments, and driver payouts. FastAPI, PostgreSQL, Socket.IO, Stripe Connect, and React Native.

## More public code

- **[Needle](https://github.com/amishaguptaberk/needle-dl-framework):** Deep learning framework built from scratch with reverse-mode autodiff, neural network modules, optimizers, and a training loop.
- **[Transformer NMT](https://github.com/amishaguptaberk/transformer-nmt):** PyTorch encoder-decoder Transformer for English-to-German and English-to-French translation.
